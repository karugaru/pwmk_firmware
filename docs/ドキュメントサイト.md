# ドキュメントサイト

## 構成

ドキュメントサイトはDoxygenで生成します。

- `src/`: CソースとヘッダーのDoxygenコメント
- `docs/`: プロジェクトのMarkdownドキュメント
- `README.md`: サイトのトップページ
- `site/`: 生成された静的HTMLサイト

## サイトを生成する

Doxygenを導入し、リポジトリルートで次を実行します。

```bash
sudo apt-get update
sudo apt-get install -y doxygen
uv sync
uv run tools/generate_docs.py
```

生成後は `site/index.html` をブラウザーで開くとサイトを確認できます。
別の出力先を使用する場合は `--output` を指定します。

```bash
uv run tools/generate_docs.py --output /tmp/pwmk-docs
```

`site/` は生成物のためGit管理対象外です。生成スクリプトは毎回出力先を削除してからサイトを作り直します。

## GitHub Pages

`.github/workflows/docs.yml` は `main` ブランチへのpush、または手動実行でサイトを生成してGitHub Pagesへ公開します。
リポジトリのSettingsで、PagesのSourceを `GitHub Actions` に設定してください。
