# プロファイル設定

このドキュメントは `uv run tools/generate_profile_docs.py` により自動生成されます。
`keyboard-layout.json` の内容は KLE互換の(非raw)JSON形式で記述します。

## トップレベル

| 項目     | 型              | 必須 | 既定値 | 説明                                                  | 制約 |
| -------- | --------------- | ---- | ------ | ----------------------------------------------------- | ---- |
| cmake    | CMakeProfile    | はい | -      | ビルド時の CMake 設定。                               | -    |
| board    | BoardProfile    | はい | -      | 基板の配線とレイアウト設定。                          | -    |
| keymap   | KeymapProfile   | はい | -      | キーコードとキーマップ設定。                          | -    |
| settings | SettingsProfile | はい | -      | スリープ、LED、ポインティングデバイスなどの動作設定。 | -    |

## cmake

ビルド時の CMake 設定。

| 項目       | 型      | 必須   | 既定値 | 説明                           | 制約         |
| ---------- | ------- | ------ | ------ | ------------------------------ | ------------ |
| board      | string  | はい   | -      | PICO_BOARD に渡すボード名。    | 最小文字数 1 |
| enable_usb | boolean | いいえ | true   | USB 機能を有効にするかどうか。 | -            |
| enable_ble | boolean | いいえ | true   | BLE 機能を有効にするかどうか。 | -            |

## board

基板の配線とレイアウト設定。

| 項目               | 型                                    | 必須   | 既定値 | 説明                                                                                                                                 | 制約                                                                        |
| ------------------ | ------------------------------------- | ------ | ------ | ------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------- |
| rows_pins          | list[integer]                         | はい   | -      | キーマトリクスの行ピン番号一覧。                                                                                                     | 最小要素数 1                                                                |
| cols_pins          | list[integer]                         | はい   | -      | キーマトリクスの列ピン番号一覧。                                                                                                     | 最小要素数 1                                                                |
| gpio_sda_pin       | integer                               | はい   | -      | I2C の SDA ピン番号。                                                                                                                | -                                                                           |
| gpio_scl_pin       | integer                               | はい   | -      | I2C の SCL ピン番号。                                                                                                                | -                                                                           |
| gpio_dr_pin        | integer                               | はい   | -      | Pinnacle のデータレディ信号を受けるピン番号。                                                                                        | -                                                                           |
| gpio_led_pin       | integer                               | はい   | -      | ステータス LED を接続する GPIO ピン番号。                                                                                            | -                                                                           |
| led_count          | integer                               | いいえ | 1      | 接続する LED の個数。                                                                                                                | 最小値 1                                                                    |
| pin_settle_time_us | integer                               | はい   | -      | マトリクス走査時にピン状態が安定するまで待つ時間。単位はマイクロ秒。                                                                 | 最小値 0                                                                    |
| layout             | list[tuple[integer, integer]]         | はい   | -      | 物理配列とマトリクス座標の対応。 例として、[[1,1],[2,3]]の場合、keymap[0]が行1列1のスイッチ、keymap[1]が行2列3のスイッチに対応する。 | -                                                                           |
| vial_unlock_combo  | list[tuple[integer, integer]] \| null | いいえ | null   | Vial のロックを解除するために同時押しするキーのマトリクス座標一覧。省略時はレイアウト先頭の3キーを使用する。                         | 最小要素数 1, 最大要素数 14, 候補: list[tuple[integer, integer]], null 許容 |

## keymap

キーコードとキーマップ設定。

| 項目          | 型                | 必須   | 既定値 | 説明                                                 | 制約 |
| ------------- | ----------------- | ------ | ------ | ---------------------------------------------------- | ---- |
| user_keycodes | dict[str, string] | いいえ | -      | ユーザー定義キーコード。キーが名前、値が展開先の式。 | -    |
| keymap        | list[string]      | いいえ | -      | layout の有効キー数に対応するキーコード一覧。        | -    |

## settings

スリープ、LED、ポインティングデバイスなどの動作設定。

| 項目                       | 型                      | 必須   | 既定値 | 説明                                                                         | 制約                             |
| -------------------------- | ----------------------- | ------ | ------ | ---------------------------------------------------------------------------- | -------------------------------- |
| device_name                | string                  | いいえ | "PWMK" | USB/BLE で表示するデバイス名。                                               | 最小文字数 1                     |
| manufacturer_name          | string                  | いいえ | "PWMK" | USB/BLE で表示するメーカー名。                                               | 最小文字数 1                     |
| usb_vid                    | integer                 | いいえ | 51966  | USB デバイス記述子で使用するベンダー ID (VID)。                              | 最小値 0, 最大値 65535           |
| usb_pid                    | integer                 | いいえ | 16385  | USB デバイス記述子で使用するプロダクト ID (PID)。                            | 最小値 0, 最大値 65535           |
| deep_sleep_timeout_seconds | integer                 | はい   | -      | 無操作時にディープスリープへ移行するまでの時間。単位は秒。                   | 最小値 5                         |
| led_brightness             | integer                 | はい   | -      | LED の明るさ。1 から 255 の範囲で指定する。                                  | 最小値 1, 最大値 255             |
| debounce_time_ms           | integer                 | はい   | -      | キースイッチのデバウンス時間。単位はミリ秒。                                 | 最小値 0                         |
| mouse_move_delta           | integer                 | はい   | -      | マウスキー 1 回分のカーソル移動量。                                          | 最小値 0                         |
| mouse_move_thresh          | integer                 | はい   | -      | マウス移動イベントとして送信するための移動量の閾値。                         | 最小値 0                         |
| mouse_wheel_delta          | integer                 | はい   | -      | ホイール操作 1 回分の移動量。                                                | 最小値 0                         |
| mouse_wheel_thresh         | integer                 | はい   | -      | ホイール移動イベントとして送信するための移動量の閾値。                       | 最小値 0                         |
| use_pinnacle               | boolean                 | いいえ | true   | Pinnacle トラックパッドを使用するかどうか。                                  | -                                |
| ble_persist_selected_slot  | boolean                 | いいえ | true   | 選択中の BLE 接続スロットを再起動後も維持するかどうか。                      | -                                |
| pinnacle                   | PinnacleProfile \| null | いいえ | null   | Pinnacle 使用時の回転、加速度、速度設定。use_pinnacle が true の場合は必須。 | 候補: PinnacleProfile, null 許容 |

### settings.pinnacle

Pinnacle 使用時の回転、加速度、速度設定。use_pinnacle が true の場合は必須。

| 項目   | 型     | 必須 | 既定値 | 説明                                                             | 制約         |
| ------ | ------ | ---- | ------ | ---------------------------------------------------------------- | ------------ |
| rotate | string | はい | -      | Pinnacle の回転設定。PINNACLE_ROTATE_0 などの定数名を指定する。  | 最小文字数 1 |
| accel  | number | はい | -      | Pinnacle の加速度設定。移動量は delta^accel*speed で計算される。 | -            |
| speed  | number | はい | -      | Pinnacle の速度設定。                                            | -            |
